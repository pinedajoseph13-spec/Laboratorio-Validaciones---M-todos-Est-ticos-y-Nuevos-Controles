## Contenido del Repositorio
En esta seccion estaremos viendo la parte del laboratorio 3 de la clase de Herramienta de Programacion Aplicada
> El primero es de DataGridView, donde podremos crear tablas de tipo SQL y tambien podremos agregar informacion y tambien eliminar toda la informacion guardada.
